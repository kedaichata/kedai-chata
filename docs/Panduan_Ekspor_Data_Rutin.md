> Status: **draf**. Pagar dan aturannya sudah pasti (dari `AGENTS.md` bagian 4 dan 8). Langkah klik di dashboard dan daftar tabel **belum diisi**; diisi di sesi LNC.02 dari screenshot layar asli, supaya tidak ada nama menu yang dikarang.
> Panduan ini tidak memuat data pelanggan, rahasia, atau alamat nyata.

## Tujuan

Paket gratis Supabase tidak punya backup otomatis. Ekspor rutin = cadangan **data** (isi tabel). Cadangan skema sudah ada di repo (`supabase/`).

## Sebelum mulai (pagar)

1. Buka dashboard Supabase di **profil browser terpisah atau jendela privat**. Login memakai akun **ketua**, bukan akun lain yang tersimpan di laptop.
2. Pastikan nama project yang terbuka adalah **ChATA**, bukan project lain.
3. Siapkan folder tujuan **di luar folder repo** (bukan `CHATA/`). Hasil ekspor memuat data pelanggan.
