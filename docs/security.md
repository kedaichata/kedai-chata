---

## 1. Tujuan

Aplikasi ini dipakai nyata, repo-nya **public**, dan memuat data pribadi (nomor WA, alamat, lokasi sekolah anak). Dokumen ini memastikan tiga hal: **siapa pun tidak bisa melihat atau mengubah data yang bukan haknya**, **harga dan status order tidak bisa dimanipulasi dari HP**, dan **tidak ada rahasia atau data pribadi yang bocor lewat repo, md, chat, atau notifikasi.**

## 4. Cara Membuat Bukti

1. **Balasan server:** tempel isi balasan (status dan pesan) dari alat yang dipandu AI. Samarkan token dan data nyata.
2. **Query baca-saja:** dijalankan di SQL Editor (akun ketua); tempel hasilnya. Query hanya `SELECT`.
3. **Screenshot:** hanya data dummy. Wajah, rumah, seragam, nomor, dan alamat nyata tidak boleh ada.
4. **Dua akun customer** diperlukan untuk SEC-05 dan SEC-09 (`AGENTS.md` bagian 10 butir 4).
5. Temuan **P0** yang gagal langsung dilaporkan ke ketua dan diperbaiki sebelum lanjut.
6. **Bukti tidak disimpan.** Bukti ditempel dan diperiksa bersama di chat saat sesi tes, lalu tidak disimpan di md, repo, atau tempat lain. Dokumen tes hanya memuat kasus uji, bukan hasil dan bukan screenshot.

| Kunci privat VAPID bocor        | Buat pasangan kunci baru; langganan push lama harus daftar ulang.                                                                                                                                                      |
